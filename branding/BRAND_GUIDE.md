# Pitfile — Brand Guide

**Working tagline (proposed):** Every service, on file. Every deadline, on time.

## The mark
A service page with a folded corner and an odometer gauge: the record and the mileage in one mark.

## Files
| File | Use |
|---|---|
| `pitfile-app-icon.svg` / `.png` | App Store / home screen icon. 1024×1024, opaque, square (the system applies the rounded mask). |
| `pitfile-mark-on-light.svg` / `.png` | Transparent mark for light backgrounds. |
| `pitfile-mark-on-dark.svg` / `.png` | Transparent mark for dark backgrounds. |
| `pitfile-wordmark-on-light.svg` / `.png` | Mark + name + tagline for light backgrounds. |
| `pitfile-wordmark-on-dark.svg` / `.png` | Mark + name + tagline for dark backgrounds. |

## Palette
| Name | Hex | Use |

## Type
Headings and numbers: SF Pro Rounded (bold). Body: SF Pro (system). The wordmark SVGs reference these fonts by name, so **convert the text to outlines in a vector editor before using a wordmark in print or on the web**, otherwise it will fall back to another font on machines without them.

## Voice
Practical and to the point, like a good mechanic. Say what is due and when. No car jargon unless the owner used it first.

## Name check
On 2026-10-14 a search of the US App Store found no app titled exactly "Pitfile". This is not a trademark search and not a guarantee the name will be accepted: check App Store Connect name availability and run a USPTO search before committing. Alternates considered: Clutchbook, Tuneslip.

## Icon rules
- Keep the mark inside the central ~80% of the icon canvas.
- No text on the icon.
- Check the icon at 60×60 pt and in dark, tinted and clear iOS appearances before submission.
